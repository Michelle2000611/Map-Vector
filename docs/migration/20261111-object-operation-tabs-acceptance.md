# 面与线操作页签验收

用户批准后完成以下布局：

- 面：外观属性、选择与编组、面合并、面修复、对象来源。
- 线：外观属性、选择与编组、线编辑、线检查、对象来源。
- 隔离线仍通过线编辑恢复；文字页签和残影流程不变。

面合并新增独立表格：选择、合并组、面数、面积、检查结果、操作。每组来自后端共享边连通分组，不在前端把点接触或近邻误判为共享边。支持全选合格组、风险核对、定位、加入画布选区、单组合并和一次分组合并。

## 数据与操作保护

- 直接预览及查找候选都收集边界风险。仅查找候选会扩大检查对象集；直接预览保持当前选区。
- 风险证据缺失、原图颜色对照缺失、标签不同、疑似边界和未知风险都需人工核对。
- 跨标签合并默认关闭，设置后仍需核对。设置在请求期间不可修改。
- 风险与分组证据必须来自同一版本；执行前对所选组重新生成精确预览，校验版本、对象集合、分组依据及可用的特征摘要。
- 无效或未应用的批量属性草稿阻止合并，避免多选自动保存跳过批量草稿的原有行为导致内容丢失。
- 页签保持挂载；晚到的预览不强制切回面合并；跨会话、图层和对象的结果失效。
- 原面修复、线检查、碎面修复刷、线面转换、独立文字、批量属性、撤销等入口保留。
