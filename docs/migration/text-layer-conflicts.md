# 文字与面、线的重复识别处理建议

本次说明文字与几何冲突的保守处理方式。系统提供独立的文字审核阶段和只读残影证据检查；证据只用于人工复核，不会自动修改几何。原始扫描、识别工件及编辑状态应保持独立，不能直接改写原图或不可变识别基线。

## 问题边界

面线识别处理图像颜色和笔画，OCR 处理文字内容及位置。同一个文字笔画可形成小面、短线和文字候选。另一方面，文字标注覆盖真实地质面、接触线或断层时，三层空间重叠合法。禁止把 OCR 外接框内的面线一律删除，禁止把地层代号等地质符号仅因像字就自动剔除。

## 建议流程

1. 用原图中的文字检测四边形（不是文字锚点）建立候选区域，结合实际笔画掩膜、OCR 一致性和人工确认，区分“字的笔画”与“框里的背景”。OCR 置信分数不能单独作为几何删除依据。
2. 对疑似文字碎面计算笔画吻合度、尺度、邻接和背景归属。只有背景归属明确时才合并；触及多个地质面、真实孔洞或接触边界时保留并待人工判断。不能用大面积填补遮住未知地质结构。
3. 对短线检查文字形状吻合、框内长度比例、与框外线网连接和地质角色。可确认的文字残线进入可恢复的隔离状态；跨框继续延伸、断层/接触线或归属不明的线保留。判断应支持线段级，而不整条抹去。
4. 文字语义对象保留原文、建议文字、检测四边形、引擎/模型和审核状态。已存在文字优先关联，不重复生成文字对象。引擎分歧保留候选供审核。
5. 提供联动预览：原图、疑似文字笔画、拟修复碎面、拟隔离线以及受保护边界。应用为独立编辑命令，记录修订、受影响对象和来源关系，可撤销。几何完整性、覆盖、拓扑和坐标一致性需在应用后校验。

## 当前系统已有能力

- 工作流为项目与原图 → 识别任务 → 编辑与审核 → 质量与范围 → 保存与导出。编辑与审核在同一画布工作区提供面线编辑、文字审核两种模式，业务记录和命令仍各自独立。持久化阶段编号不重排：旧阶段 2、3 映射到新步骤 3，阶段 4、5 对应步骤 4、5；旧阶段 2 或 3 均可推进至阶段 4。
- OCR 置信度只用于内容分流建议；高分普通文字可自动放行，地质代号、引擎分歧、改写文字、特殊符号等进入待审核。自动放行不写入人工确认事件。模型分数未经校准，不能当作准确率。
- 文字残影检查基于原 OCR 框及原图暗色笔画吻合、碎面尺度和线的框内程度生成只读疑似项。颜色碎面只有与原图墨迹充分重叠时才提示。
- 内容审核状态与面线清理状态分别显示。用户可检查列表、定位文字并预览局部清理；应用清理仍是另一个可撤销编辑命令。
- 完成文字步骤不要求逐条人工确认；待审核状态会保留并由正式导出策略按规则处理。

- text_residue 预览支持基于选中文字或局部范围识别碎面、邻接背景与可疑线条。
- cleanup_text_residue 保留目标文字和审核证据，线条可以隔离并恢复，归属不确定的面需要明确指定或保留。
- 当前规则使用尺寸、范围内比例及邻接关系；不是完整的文字笔画分割或跨层语义融合。
- 现有局部文字残影范围存在大小限制，长文字、多方向文字和跨地质边界场景仍需专项验证。

## 长期数据模型

建议把跨层冲突记录为独立的候选关联：文字候选/对象 ID、面/线 ID、识别运行 ID、关系类型（疑似文字笔画、保护地质边界、已隔离、人工拒绝等）、判定依据、审核状态及编辑命令 ID。每层仍使用稳定对象 ID 和自身几何类型，不靠把几何对象改成文字对象解决冲突。清理状态与文字识别/文字审核状态独立。

## 后续验收

需要包含文字位于单一色块、文字压接触线、跨多个地质面、地层代号、旋转文字和连接框外断层的真实样本。指标应同时衡量去残影效果和真实地质要素误删率；清理后显示更干净不足以证明结果正确。

## 文字痕迹预览

点击所选文字残影后，原图上以橙色填充疑似碎面、紫红色显示疑似短线、蓝色虚线显示需保留核对的线。蓝线裁切在当前检查框内展示，显示裁切不改变原始几何。默认隐藏常规面线与重绘文字，避免遮挡扫描笔画；可独立切换各类痕迹和其他面线，并退出预览恢复原有显示。邻接底面不作为文字笔画高亮。只读评估发现但局部清理计划未包含的对象单列数量，展示证据不会扩大实际清理范围。

## 残影清理与文字对象隔离

文字残影显示开关位于画布标题栏右侧，负责查看。右侧残影清理计划列出实际将合并的碎面、隔离线段、保留碎面与线段数量；待定组指定归属或线段勾选时实时更新，显示开关不改变执行计划。清理现有文字的面线时不提交文字修改，后端也忽略文字表单输入并保留全部已有文字记录（含原 OCR 关联、内容版本和审核证据）。清理计划保存在 edit_preview 和命令历史中；线隔离通过 associated_text_feature_id 引用既有文字，不改写文字对象。局部补录没有现有文字时仍可创建新文字。

整图自动检测及后台缓存目前仅讨论，不在此次调整中启用。已有检查文字残影按钮按需运行，打开页面不自动扫描。

## OCR 文字尺寸与加载提示

OCR 排版通过后端统一的 ocr_layout 计算字号、未归零的角度、宽高及基线偏移并持久化，前端直接使用这些记录。历史自动文字通过正式可撤销命令修正，人工字号和位置调整保留。此前浏览器临时估字号和收缩显示的补偿已移除。OCR 是可编辑语义文字重排，字体本身无法从扫描图精确恢复；原始扫描及候选检测框始终保留。

操作与数据加载采用 Geological-Map-Digitizer 使用的 Ant Design App 上下文顶部加载提示，耗时请求显示转圈提示并在完成、失败或取消时关闭；识别和导出后台任务保持提示，不对每次进度轮询重复弹出。

## 2026年11月8日完整清理闭环修正

旧版可视化合并了证据检查候选与局部清理候选，但实际执行只处理旧60平方像素阈值的部分碎面和勾选线，因此复查可能出现相同对象。新版“预览彻底清理”以画布显示框和其候选对象为同一执行范围，随后“执行彻底清理”统一提交。原选择性命令保留接口兼容，网页使用明确的完整清理计划。

完整模式按共享边与背景面面积选择邻接接收面，维持面覆盖；蓝色待核对线和跨框线保持完整，不纳入文字清理。确定的框内短线可隔离，需另行处理保护线时在线编辑中核对。所属文字、原OCR候选、审核证据和原始影像不改写。事务复查目标残影，不要求保护线消失；无法连接背景或几何校验失败时回滚，可撤销恢复。2026年11月8日问题修复规则以此为准。

文字残影预览使用空间索引读取局部对象，命令沿用修订与范围摘要校验；完整计划的几何快照仅存数据库，不在前端响应中重复传输。局部检测只读取源影像裁剪块。前端普通几何操作后只刷新历史，样式及图层仅在相关变更时重读，避免每次文字选择与编辑刷新整图样式。

编辑与审核提供文字审核、痕迹检查与清理，也提供常规面线编辑；文字审核模式不显示图例样式编辑，切至面线编辑后保留原有样式和图层操作。操作历史使用中文动作和状态，底层稳定命令标识不变。
