# 2026-11-09 对象属性自动保存与面板验收

## 已实现

- 面、线、文字外观属性统一布局；选择与编组、几何操作折叠；对象来源之后独行删除，未选中显示简短空状态，补录/绘线仍显示创建参数。
- 单个已有对象合法输入即时画布预览，约 600 毫秒停顿或失焦后自动保存。中文输入法组合、无效数字/颜色/坐标、过长文字不提交；失败保留草稿并显示重试，空选区与多选时也能恢复旧对象失败。
- 多选混合属性显示多个值，只应用用户改动字段；“应用到 N 个对象”通过 `set_feature_properties` 一次事务和一条可撤销操作更新。
- 去除保存修改、保存并确认；文字“确认并下一条”先等待有效修改保存，再人工确认。稍后处理、导航、几何、删除和撤销协调待保存内容。
- 项目命令串行并固定目标；保存中继续输入、A→B→A、跨项目/资产/会话恢复不会被旧请求清除或串写。撤销等到同资产旧对象的保存尾部结束；旧会话失败不阻碍新会话恢复持久草稿。
- 未知网络结局重试保留完整请求体、原修订和幂等键；明确修订冲突保留草稿，要求重新加载，不自动覆盖服务器的新版本。
- `delete_faces` 删除指定面并留下空缺，不扩张邻面；索引、编组和可变样式绑定同步更新，历史支持完整撤销/重做。活动线、隔离线和单文字删除同样可恢复。
