# 线检查与10秒通知验收

## 最终交互

编辑图层选择“线”时，底部显示全宽“线检查”，沿用520px/小屏420px、收起与拖动/键盘调整。显式检查当前资产的全图active线，按“断线接续 / 疑似文字短线 / 虚线编组”显示，状态为待核对/已保留/已处理/全部。检查不会自动改对象，候选不是已确认的错误。

定位高亮原线，接续额外显示拟补连接段。核对后才能应用；多个候选分别接续或分别编组，不摊平成一条线或一个组。全选在待核对/全部视图只取无保护原因的pending候选，已保留视图用于批量重开；受保护行仍可单独选择保留。批次最多2000，超出时保留选择并说明、禁止提交。5000候选返回上限和密集端点跳过会明确提示，不假称完整无遗漏。

保留/重新纳入核对存储为检查元数据，不增加working_revision；证据改变会重开。应用先flush草稿再校验报告修订，项目/资产/会话/图层/修订/参数变化及过期取消旧结果。迟到响应不跨上下文；失败保留选择与幂等键。

已完成的全局结果提示（成功、信息、警告、错误、长结果）统一10秒；加载提示随任务结束。新线操作成功明确提示可撤销，项目历史显示“线检查修复”。

## 几何与数据边界

新geometry/application/api line_checks模块独立实现，避免旧全量editor adapter对面coverage_status和OCR的旁路修改。诊断用只读一致快照物化后关闭连接、锁外计算，最后短写缓存校验修订和资产。apply_line_check绑定预览、期限、算法版本、证据摘要、候选及完整核对集合，预检整个批次并原子提交。

端点使用有向切向及四种端点组合，保留原坐标和明确连接段。属性/测宽不相容、分叉、第三条线交叉、自交、手工线、语义线型等受保护。有效样式包括自身/绑定关系/继承层默认样式。已知虚线或规则短段子链即使邻接长线也不补间隔。文字短线需要文字空间证据，保护跨框、分界、地质符号/产状/短数字等，只提供显式隔离而不删除。

新命令只写线、必要编组/样式关系、索引及来源审计。单成员旧组或候选完全包含的安全组可接续；虚线新编组允许迁移singleton，旧组UUID行保留，含外部成员的组不被拆散。多组关联逐个检查，不能以最后一组覆盖判断。apply及undo/redo均绕过全项目OCR同步。

## 面合并建议（本轮只讨论）

按“是不是同一个地质对象”确定要素身份，再用合适几何表达：共享边可溶解为Polygon；点接触或分离但明确同一实体可组成MultiPolygon，保留实际间隙与孔洞。相同地层代号/颜色不自动代表同一要素，需要独立属性/编辑的露头仍可保留feature并共享分类或编组。

消除微缝另作接缝修复：容差基于像元、配准误差及CRS单位，限制最大位移和面积变化，检查邻面归属、无新增重叠及面覆盖，预览变化再确认。不能以buffer/凸包把真实间隙、未选中的孔洞或第三方面一并吞掉。属性冲突与来源审计、multipart及孔洞导出须明确处理；本轮未改变现有面合并命令。
