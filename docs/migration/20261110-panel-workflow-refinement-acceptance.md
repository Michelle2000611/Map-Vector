# 面检查、通知及底部面板交互验收

## 最终行为

选中单个可编辑面后，250ms防抖自动检查。检查状态只在面修复工具栏显示，不触发全局加载；保留“重新检查”作为重试入口。对象、图层、资产、修订、参数和会话变化时取消或忽略旧响应。自动检查不会自动核对或应用修复。参数未填写完整、属性草稿无效、自动保存失败和图层隐藏时不发起检查。恢复有效草稿后可重新调度，即使没有写入或修订变化。

全局操作通知统一为右上角浮层，成功/普通提示3.6秒消失，错误及长查询结果保留至关闭。加载与结果使用独立键，通用提交成功被更具体的操作结果替换，避免同一结果重复。空状态回调不会擦除错误；字段校验及候选风险仍在对应控件旁。移除“正在选择对象…”文案，点选、框选、刷选、套索和选区操作静默，保留忙碌锁及非取消错误反馈。文字审核“下一条”仍沿用既有导航加载行为。

面修复工具栏左侧为检查状态、候选数、重新检查及检查参数，右侧为全选、选择数量、核对与应用。参数默认折叠，展开另起一行；普通按钮统一样式。面修复与文字核对内容默认高度520px，小屏420px，可收起或拖动/键盘调整到240–960px。两者继续横跨包括属性栏下方的完整工作区。
