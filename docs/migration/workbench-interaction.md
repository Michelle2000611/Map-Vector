# 文字连续清理与工作区交互

局部预览从共享状态读取当前修订和选区。遇到 REVISION_CONFLICT 时仅对只读预览恢复一次：读取项目、加载与当前修订一致的资产对象、保留仍存在的选区，再重新生成预览。写入清理命令不自动重试，仍需原修订和预览一致。页面会话、资产、选区和请求序号共同校验响应；旧对象预览不覆盖新选择。失败反馈位于对象操作区，生成期间按钮显示加载状态。文字排版校准后，残影预览范围采用当前显示框与原始OCR框的并集并留出原有边距；显示框变小不会使清理漏掉复查使用的原OCR范围。

字号、角度、X和Y输入使用左标签右数值的连体格式，显示最多一位小数并省略末尾零；输入未修改时不将舍入结果回写到表单或后端。用户实际输入的小数保留输入精度，失去焦点后只格式化显示。字号单位为像素、角度为度、坐标为原图像素。

属性栏在面线编辑和文字审核中统一使用“属性与操作”标题，标题旁显示蓝色对象类型标签和“已选 x”标签；选择数量不再占据正文一行。文字内容为带“文字”字段名的整行输入。颜色使用字段名、六位十六进制值及可点击色块组成连体输入，色值无效时恢复当前颜色，查看和填写颜色不会自动提交编辑命令。

图例样式与图层保留折叠入口，用于面线外观复用和图层显示设置。已有样式、样式名称、颜色、线宽、线型、虚线段长/间隔、齿间距、齿高度和齿方向均明确标注字段。面对象不显示线型参数，线对象仅显示所选虚线或齿形的对应参数；文字与隔离线仅保留适用的图层控制。不透明度以0至100%显示，提交时转换为原有0至1的数据值。

操作历史查询按 project_id 返回项目命令序列，不按当前对象筛选；asset_id目前仅验证资产归属，不改变项目历史语义。入口位于工具栏，使用独立底部抽屉，包含中文操作名称与状态。对象属性区不再显示全项目命令历史；撤销重做继续按项目序列执行。

工具栏的查看、选择与工具、历史分别使用浅色细边框分组，组间保持10像素间距。历史紧随选择与工具，不再靠自动外边距推到最右侧；空间不足时各组按顺序换行，组内控件也可换行。不为填满工具栏增加公共功能。

步骤3“编辑与审核”将文字审核与面线/文字编辑纳入同一工作区，提供“面线编辑”和“文字审核”两种模式。画布只挂载一份，模式切换保留双图布局、缩放、滚动和当前选择；审核队列按需加载，折叠或切换模式时保留筛选、报告和分页。定位审核项会在画布选择文字并收起队列。

两种模式只共享交互工作区，不合并业务数据：文字内容审核、残影预览与清理、几何编辑命令仍有独立状态和审计记录；切换模式本身不提交编辑命令。待审核文字不阻止进入质量与范围，也不要求全部文字人工确认。旧 `/review` 路由兼容到 `/editing?mode=review`，可直接刷新恢复审核模式。

持久化 workflow_stage 编号不重排。旧阶段 2 和 3 都映射到新的步骤 3，阶段 4 和 5 分别映射到步骤 4 和 5；阶段 2 或 3 均可推进到阶段 4。识别阶段不能跳过审核编辑工作区直接进入质量或导出。
