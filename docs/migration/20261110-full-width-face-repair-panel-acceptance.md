# 全宽面修复与文字核对面板验收

## 最终交互

选择“面”时，底部显示“面修复”；选择“文字”时，同一区域显示“文字核对”。两种面板都铺满工作区宽度，包含右侧属性栏下方，单画布/双画布一致。右侧不再嵌入面修复候选列表。

公共BottomReviewPanel支持收起/展开及底部拖动调高，键盘ArrowUp/Down、Home/End可调整高度。收起时保留DOM、参数和选择，图层/对象/资产/修订变化仍清理过期预览和确认。

面修复采用表格和固定工具栏：检查当前面、折叠参数、所选候选数/去重涉及面数、核对所选、跨页全选可修复项、应用所选修复。筛选为待核对/可修复/已处理/全部。定位与画布高亮联动，执行失败保留选择供重试。缺口和缺少独立表达依据的狭长候选需显式核对，不自动进入全选可修复项。已处理记录来自真实operation审计，不能再次勾选应用；旧历史不冒充当前安全诊断或缺失识别依据。

## 几何与数据约束

新增保守boundary_gap候选，限完整邻面或完整开口区域，不裁掉所有者的其他部分。候选使用面积/宽度/长度、有效栅格、完整归属、无重叠与拓扑校验；所有边界缺口都要求人工核对。孔洞、缺口是几何类型，线/文字只作为事实性空间相交依据，不声称语义对应。

RepairFace新verified_review_candidate_ids必须唯一、属于本次选择且确为需核对候选。核对不能越过硬保护。命令保持预览/项目/资产/对象/修订/摘要/期限绑定，旧版本预览失效；成功请求的旧幂等摘要兼容保留。

面修复只改面与必要编组/样式关系、索引和来源审计。修复以及它的undo/redo显式跳过无关OCR同步，独立线、文字、OCR和原始栅格不变。历史API按来源面及资产过滤后限制最近500次操作，撤销状态实时派生。
