# 属性页签工作区验收

日期：2026-11-11。

## 最终行为

- 文字只保留外观属性、残影处理、对象来源三个页签。标记为待处理、补录文字保留在外观属性；确认并下一条移至文字表格行操作。修改属性仍自动保存，人工确认保持独立语义。
- 切入残影处理直接打开全图表格、检查并高亮当前文字。无选中对象仍能浏览全图表格。没有查看残影并清理入口或底部文字核对标题。
- 面修复与线检查置于几何工具，其他页签不显示其表格。原有批量、筛选、分页、来源链、补录、OCR 候选、隔离/恢复、确认、撤销等操作保留。
- 面、线、文字的对象来源占满剩余高度；删除对象仍为底部独立按钮。导航固定，内容在页签内部滚动；双图和移动抽屉使用同样归属。
- 页签内容保持挂载，跨页签保留 IME 及数值草稿，跨图层保留文字表格筛选。
- 自动检查不确认、不清理。晚到的检查与确认结果不得改变用户已切换的对象或图层。

## 独立检查与修复

1. 保留已选文字时框选残影，原自动入口会覆盖手动画出的范围。现在优先保留有效的区域预览；区域清理与重新核对也沿用原范围。
2. 长几何预览曾被固定高度容器裁切。现在预览及确认操作位于几何工具的滚动区，生成预览后自动显示该页签。

两个问题均先复现测试失败，再修复并通过，独立复核未发现阻塞项。
