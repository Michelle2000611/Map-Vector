# 操作按钮文案与尺寸

用户批准先修改按钮文案、条件显示与紧凑固定尺寸；面、线页签拆分及面合并表格本轮只提供设计建议。

- 面合并按钮：查找合并候选、预览合并、合并所选、分组合并。
- 面修复按钮：重新检查、检查设置、清除预览、核对所选、修复所选。
- 线手工接续按钮：预览接线、连接所选；线检查参数入口统一为检查设置。
- 常用操作按钮104×32px，长文案128px；动态删除和批量应用文案自适应宽度，表格行小按钮保留紧凑样式。
- 关联操作以不拆行的功能组布局，外层按空间换行。
- 面的核对按钮仅当选中了需要人工核对且尚未核对的候选时出现；线的核对按钮仅当所选项符合核对条件且仍有未核对项时出现。原有适用条件和业务命令不变。
