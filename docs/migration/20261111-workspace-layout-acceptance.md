## 最终布局

单画布默认左右约50/50，分栏支持指针与键盘。980/1024/1200/1580px验证最小可用宽度和无页面横向溢出；尺寸约束与ARIA值在初始/resize同步，窄屏沿用属性抽屉。右侧一个“属性与操作”标题，类型/已选数量在标题右，无对象概览、标题下分隔线或纵向调整手柄。定位按钮仅在结果画布复位左侧，定位先flush草稿并复查对象上下文，文本使用显示边界框。

属性使用外观属性/选择与编组/几何工具/对象来源/文字核对/残影处理页签，仅展示当前图层适用项。forceRender且不destroy隐藏页，保持原输入DOM、无效值、IME、待保存/失败草稿；切新对象默认回外观。来源JSON按激活显示、来源链按按钮请求，删除位于来源末尾。保存中/错误/无效状态和重试仍可见，只移除空闲“修改后自动保存”。

面修复/线检查/文字核对在右侧原组件中工作，单/双切换用CSS重排、不移动React父树或复制实例。双图保留两画布、属性栏和全宽底部检查，折叠/原高度调整可用。小屏属性抽屉与下方检查可达。表格在容器内部横向滚动，不把最后的查看/定位操作裁掉。

“工具”“属性与操作”“当前结果与差异”“原图与基线对照”在桌面统一16px。工具栏设计没有改成之前讨论的新方案。
