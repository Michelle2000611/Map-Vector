# 最终代码审查记录

本轮尝试分配接口/前端实现与独立审查子任务，但返回均为准备就绪，没有实际代码或审查文件。因此不把这些返回记作独立审查通过；以下为主线实际代码审查与回归证据。

已修复的重要发现：

- 合并和删除后失效 ID 残留在选区，导致下一次查询被 SELECTION_SCOPE_INVALID 拒绝。编辑响应同步 remove 选区；线合并→再选→拆线浏览器用例通过。
- 快速连续属性操作可能同时使用旧 revision。前端提交互斥，顺序“保存并确认”读取最新 Zustand 修订；独立浏览器用例验证两次提交。
- 字形跨进视口但锚点在视口外时漏查询。新增 text_display_index，编辑、历史、恢复维护并首次迁移回填；viewport 和移动回归通过。
- 项目切换旧请求和属性元数据可能回写。统一 AbortController、会话检查、元数据序号与卸载失效；延迟旧请求浏览器用例通过。
- 导出原为同步，失败不留可查询资源。新增冻结快照后台进程、持久状态、取消、恢复、错误与受控下载；排队取消、运行中取消、孤儿恢复及失败下载回归通过。
- 存储接口重构后测试目录变长触发 Windows MAX_PATH。导入临时目录缩短并移至同卷目标父目录，最终项目结构不变；导入4项定向复测通过。
- 导出 finished_at 曾使用写入前时间，低估等待耗时。改为提交前实际 UTC 时间，后台响应从起止时间派生 elapsed_ms。
- Paddle 能力检查只看解释器，未查独立发行包版本。环境诊断和任务固定均记录 Paddle/PaddleOCR/PaddleX/NumPy 版本，执行前核对。
- 多个文字显示框重叠时残影适配器默认复用首行，可能清理错对象。执行时把冻结内核预览候选限定到明确文字ID；未指定目标且多对象的框选拒绝，5项文字/高级回归通过。

冻结内核参数、接线顺序、风险阈值和审核政策保持原基线。外部 GIS、真实图全部问题位置、跨平台和许可证核准仍需独立验收，自动代码审查不替代这些结论。
