## 交付行为

- 当前文字直接点击“清理残影”，系统自动生成完整计划并提交，不要求手动预览。没有可清理对象时只提示，不提交命令；计划失败、对象切换或修订不符时不误提交；写入失败不自动重试。“查看范围”只生成范围高亮。
- 移除“预览彻底清理”“执行彻底清理”和大段说明。范围面板只保留数量、定位与折叠详情；进度提示使用“正在清理文字残影”或“正在查看残影范围”。
- 保留“保存并确认”“保存修改”，删除独立“确认文字”。“稍后处理”与“保存并确认”成功后进入最新队列中的下一条待核对文字；“下一条”只导航。失败停留、空队列停留；请求中继续输入的新草稿保留在当前对象，清理不提交文字输入。
- 面板改名“文字核对”，提供待核对、稍后处理、已确认、全部四种筛选；待核对包括 required 与 manual_edited，已确认只包含人工确认。仅剩人工修改项时“下一条”仍可用。
- 主表四列：文字、需核对项、状态、查看。识别分数、原始候选与上下标详情按需展开，需核对上下标保持明显标记。操作统一在右侧完成。
- 面板右上“检查全图残影”“更多”“刷新”。分数门槛、重新评估、恢复识别排版与未采用识别结果收入“更多”；筛选、分页、门槛和检查报告跨图层隐藏保留。
