# 2026-11-10 属性折叠、批量删除、面修复与核对表整合

本轮开始于11月9日，最终验收于11月10日；运行证据保留在 `runtime/face-repair-design-20261109/`。

## 交付行为

- 面、线、文字的外观属性均采用同款折叠标题，默认展开；文字核对、残影处理默认展开且可折叠。折叠不销毁输入/草稿/输入法状态，保存失败与重试在折叠外仍可见。属性区普通操作采用默认按钮，删除保留危险样式。
- 面、线沿用画布多选后来源下方“删除 N 个对象”；文字补齐多对象原子删除。列表可勾选当前页文字，出现批量删除条；翻页、筛选、对象离开当前可见页时清选，避免隐藏选择。失败保留勾选；一次删除可一次撤销，不级联删除独立面线。
- 文字核对与残影检查合为feature_id唯一行的主表。原始候选、分数、上下标等列保留，新增残影证据。真实review_status与扫描建议分开，扫描结果不能覆盖人工确认；未检查/失败/过期不显示为无残影。报告绑定项目、资产、修订；批量写经自动保存屏障。

## 面几何修复

新增 `pixel_tail_ownership_v1` 候选算法与受控应用命令，不修改 frozen B2c 识别器或自动批量替换既有成果。

- **去除线状附着**：在保守支持的像素面上寻找窄枝候选，排除整体窄体、连接多个主体的桥和不明确切口；候选默认不选。用户指定共边接收面，将精确候选从源面转移到接收面，保持面覆盖。接收面在画布中另色勾边。
- **填充孔洞**：只允许未占用、有效原图内、满足面积条件的真实空洞。被其他面或同一MultiPolygon的其他部分占据的孔显示为已占用，不允许直接填充；这类情况需要核对后使用面合并。
- 相交UNKNOWN/SPLIT线或文字时默认保护。仅针对原因为 `PROTECTED_LINE_OR_TEXT` 的候选，逐项勾选已核对相交对象后，才可继续选该候选和接收面；其他保护原因不能绕过。独立线、文字及其属性不写入修复事务。
- 预览绑定项目/资产/源对象/修订/输入摘要/有效范围/过期时间。应用使用存储几何和合法接收面，不接收任意客户端几何；检查有效性、无新增重叠、面积守恒、源面不被拆散。一次事务保留精确前后几何与人工核对审计，支持撤销重做。
- 该工具的候选阈值是核对辅助，不能作为真实地质归属真值。自动识别阶段默认算法未改变，避免无真值的全图开闭运算误伤狭长地质体。

## 真实样本结果

截图对应青色面 `2d081611-5d76-449d-afe2-e8a98d3f87ea` 是单Polygon。诊断得到两条2px窄枝，面积84与53px²；5个内环合计39px²已被其他面占据，真实空洞为0。

独立临时副本中，默认保护请求被拒绝；逐项核对两枝、指定接收面后转移137px²，源面面积14439→14302。全18992面覆盖仍有效，gap=0、overlap=0；所有独立线、文字及完整属性逐行不变，撤销恢复原几何。证据见 `geometry/real-repair-evidence.json`、`geometry/real-manual-repair-comparison.png`。这项验收证明几何安全和可操作性，不代替外部地质归属认证。
