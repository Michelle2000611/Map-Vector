# 2026-11-09 编辑工作区整理验收

本次依据用户六项界面要求及后续确认完成整理。坐标区采用 X/Y/W/H 四格，W/H 只读；主按钮为“保存并确认”，旁边保留“保存修改”；不透明度按最新要求使用拖动滑块。

## 交付行为

- 不透明度移至顶部“查看”区，范围 0–100%，显示百分比。拖动即时预览，松开后单次保存；键盘操作、0%、保存失败恢复及跨图层隔离均有验证。移除“图例样式与图层”编辑区，已有样式仍用于渲染。
- X/Y 保留原有锚点语义和完整精度草稿。W/H 根据已保存的 `display_bbox_px` 计算，表示旋转后的轴对齐边界框宽高，缺失或无效时显示“—”。只读尺寸不进入修改请求。
- 文字操作分为“保存与审核”“补录与残影”，删除单独置底；面线按钮使用明确的对象和动作名称。删除“在结果画布选择对象后修改属性”。
- 移除独立模式切换行，文字审核并入编辑工作区。选择文字图层时，双画布下方出现“文字审核与残影”；切层隐藏审核栏时保留筛选、门槛、分页和报告状态。兼容旧 review 链接和浏览器导航。
- 去掉“底图”“显示”的可见文案，底图选择保留无障碍名称。
- 隐藏当前编辑图层时，在工具栏显示提示和恢复显示按钮；画布不再叠放该提示。隐藏图层的编辑限制保留。
- 切换审核对象、补录或图层时清理旧对象预览，避免上一对象的残影预览留在新对象上。
