# 属性面板紧凑化计划

用户要求删除无选择空提示、标题字体与工具一致、字段颜色/宽度/用途简化、输入每行两列、按钮固定尺寸，并评估删除位置。沿用其持续实施授权，不重新暂停确认。

## 最终设计

- 不显示“在画布选择x对象后编辑属性。”，不补替代文案。
- 属性标题使用Ant Design主题字体（与工具Card相同），字号16/字重600保持。
- 输入每行两列；文字内容/颜色先一行，字号/角度一行，X/Y和只读W/H仍两列。原图裁剪、位置分组标题跨行，不能变成四个超窄列。单个参数占半行，所有输入最小宽度不溢出。
- 常规操作144×32px，长文本/加载不裁掉文案；表格行内查看/定位沿用紧凑尺寸，页签不是普通操作按钮。
- 删除固定为右侧底部红色144×32按钮，所有页签可达，取消来源页中的重复按钮；双图右属性底部保留，手机放原属性Drawer footer。保留多选数量、完整确认、草稿flush和可撤销语义，不修改命令处理。
- 只改前端；不在真实项目中编辑或删除数据；不提交/推送；所有测试输出在repo/runtime/property-compact-20261111。
