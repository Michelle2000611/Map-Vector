# 单画布左右工作区 Implementation Plan

**Goal:** 落实用户已确认的左右分栏和右侧属性/检查融合，工具栏保留原样，所有原功能可达；同时完成此前已讨论的识别计时、预览页签和导航简化。

**Architecture:** 新增独立WorkbenchFrame承载最终50/50可调整分栏，右侧统一“属性与操作”标题、类型和选区标签，无对象概览与纵向拖动。Workbench保留现有工具/画布/命令，属性改forceRender页签。检查实例保持同一React父树位置，单/双画布通过CSS布局切换，不能重挂载丢失候选。BottomReviewPanel侧栏适应高度，双图/小屏底部模式保留既有高度控制。

**Tech Stack:** React/TypeScript/Ant Design/CSS；Playwright浏览器回归；无后端或契约变化。

## Global Constraints

- 用户已明确批准布局方案，工具栏的控件、文案和事件处理保留；不再要求确认。
- 不增加侧栏对象列表或对象概览；类型/数量放在“属性与操作”标题右，定位移至结果画布“复位”左。
- 单画布桌面初始画布/侧栏约50/50，分隔条可拖动/键盘调节；右侧不保留纵向调整。
- 双图模式保留两画布、属性及全宽底部面修复/线检查/文字核对；相同组件不复制、不丢状态。
- 旧属性、批量修改、自动保存、IME/无效输入、草稿恢复、撤销重做、来源、删除、所有几何工具、检查预览/核对/应用/保留/历史都保留。
- 不改变面/线/文字算法，不在真实项目执行编辑验收，不提交/推送未跟踪业务源码。
- 所有证据在repo/runtime/layout-redesign-20261111，禁止D盘根目录测试输出。
- 识别状态显示正在识别/该类耗时/整体耗时，无进度条，保留取消重试/运行详情/结果保存。时间用实际事件，终态停止，未知显示—；不伪造独立面/线耗时。
- 识别预览改为全部/面/线/文字下划线页签，保留原图层过滤逻辑。仅导航标题及下一步文案去掉“与”，路由/阶段ID不变，其他文案不全局替换。
