# 面板交互与通知调整

**目标：** 选中面后自动检查，统一全局通知位置，清理面修复工具栏，增加面修复/文字核对默认高度，并给出线层底部面板的功能建议。

**交互：** 操作结果和加载提示统一到右上角浮层，不撑动画布；成功自动消失、失败可关闭，表单与候选风险仍在对应位置显示。选中单个可编辑面自动安静检查，支持重新检查；切换对象、图层、资产和修订时忽略旧响应，绝不自动核对或应用。

**布局：** 工具栏左侧放当前检查状态/重新检查和参数入口，右侧放选择数量/全选/核对/应用；参数默认折叠展开后另起一行。普通按钮保持统一，数量和状态不挤在按钮之间。两个底部面板默认内容高度从360增加到520px（小屏按视口适配），允许继续拖动/键盘调整。

**范围：** 线层本轮只评估，不自动新增未经讨论的识别算法或空面板。图层、草稿、自动保存与幂等队列约束保持；不自动修改真实项目成果。
