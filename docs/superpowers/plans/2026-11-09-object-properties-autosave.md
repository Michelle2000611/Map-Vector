# 对象属性面板与自动保存实施计划

用户已批准 2026-11-09-property-panel-design-options.md 中建议。使用 test-driven-development、subagent-driven-development、verification-before-completion 连续实施；不提交现有未跟踪业务代码。

**目标：** 单对象合法属性即时预览、约600ms停顿或失焦自动保存；多选明确应用；文字独立确认；三类面板结构统一，删除真实可撤销并在对象来源之后。

**架构：** 独立自动保存控制器管理去抖、草稿与状态；App 项目命令串行队列固定项目/资产/会话，顺序使用最新修订。Workbench 负责预览合成、动作前保存与面板分组。后端新增面删除和面线原子属性修改，复用历史事务。

## 约束

- 自动保存仅单个已有对象的合法属性；中文输入法组合与无效数字/颜色不提交，失败保留草稿、明确状态及重试。
- 连续输入合并为一次写入；保存中新增输入在后续写入，失败不得覆盖新草稿。同项目不同对象不串用属性；跨项目/资产会话的旧队列不得写入新目标。
- 用户改动字段才进入请求；多选不同值显示“多个值”，保留“应用到 N 个对象”，面线批量属性一次事务、一次撤销。
- 自动保存不等于人工确认。确认前等待合法修改保存，再确认并进入下一条；几何预览、删除与历史动作需协调待保存内容，防止撤销后计时器写回。
- 面删除只删除明确选中的面，留下空缺，不自动扩张邻面；清理索引和编组关联，保留可撤销历史。线、隔离线与文字删除同样真实可恢复。
- 默认外观属性常驻，选择与编组、几何操作折叠；对象来源在删除之前，删除独占底行。无选区用空状态；创建工具保留参数。
- 已完成的文字页签/七列、清理保护、画布缩放滚动及路由兼容保留。验证只用模拟API或独立副本，禁止原项目写验收数据。
