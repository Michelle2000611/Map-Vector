# 面与线操作页签

用户已批准拆分方案，直接实施。

- 面：外观属性、选择与编组、面合并、面修复、对象来源。
- 线：外观属性、选择与编组、线编辑、线检查、对象来源。隔离线在“线编辑”保留恢复操作。
- 面合并表每行代表后端 merge_faces 返回的共享边连通组：选择、合并组、面数、面积、检查结果、操作。查找候选先使用 merge_suggest，再对种子及候选生成 merge_faces 预览，不在前端推测共享边。
- 多组分别合并仍使用 merge_face_components；单组合并使用 merge_adjacent_faces。每次执行前生成所选组的精确预览，匹配对象、版本、会话及有效期。
- 跨标签默认禁止；疑似边界、未知风险和原图色差证据须人工核对。核对只记录当前预览下的临时决定，不修改业务对象。表格可全选合格组、定位组、采用组为画布选区。
- 面修复和线检查保留现有表格、筛选、参数、批量操作、状态和撤销；所有页签保持挂载，切换不会丢失表单或检查状态。
- 非文字预览自动切到所属页签；碎面修复刷归面修复，接线和线面转换归线编辑。
- 保持104×32px按钮、长文案128px、来源全高、导航固定、单画布50/50可拖动及移动端兼容。
- 不修改后端及正式项目数据。测试输出只在仓库 runtime，8841提供构建。
