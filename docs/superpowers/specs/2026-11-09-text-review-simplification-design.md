# 文字核对与残影操作简化

用户已批准本轮讨论方案，持续实施，无额外审批点。

## 已确认交互

- 当前文字提供“清理残影”主入口，后台自动生成完整清理计划并执行，不要求先手动预览。保留“查看范围”作为只读入口。保留现有后台修订、范围、几何归属和事务复查，失败不自动重试写入；无法确定时不修改对象。
- 清理计划缩成一行数量和可展开“详情”，去掉“彻底”、重复说明和二次预览按钮；原始依据仅在详情内。
- 删除重复“确认文字”，保留主按钮“保存并确认”和“保存修改”。“暂时跳过”改为“稍后处理”；保存并确认和稍后处理成功后定位下一条 required 文字；“下一条”只导航。失败不跳转，切层或切项目后的旧请求不带走新选区。所有未保存输入继续按原草稿规则保留。
- 下方面板命名“文字核对”；待核对、稍后处理、已确认、全部作为可点击筛选，取消显示全部复选框。自动通过仍明确区别于人工确认。
- 面板右上放“检查全图残影”“更多”“刷新”；更多收纳自动通过分数、重新评估文字、恢复识别排版和未采用的识别结果。
- 主表显示文字、需核对项、状态和“查看”；查看只定位并选中，右侧统一操作。原始候选、识别分数、上下标详情进入展开详情；需要核对的上下标始终可见。
- 筛选、分页、门槛和检查报告跨图层隐藏保留；画布尺寸、缩放、滚动及草稿行为保持。

## 验证边界

使用模拟 API 浏览器验证写请求、自动导航、失败与异步切换保护，并复用现有后端清理回归验证边界线、文字和撤销。实际项目只在隔离副本验证。测试仍忽略、不提交现有未跟踪业务代码。
