# 属性页签内的检查工作区

用户本轮指令授权直接调整对象来源、残影处理、面修复、线检查的归属；沿用此前不重复询问的要求。

- 文字页签为外观属性、残影处理、对象来源。外观属性保留标记为待处理和补录文字；确认改为表格中的可选操作，保留人工核对状态，不以自动保存代替确认。
- 面修复和线检查放入各自的几何工具。文字全图表格只在残影处理页签可见，删除原有底部文字核对标题、收起按钮和查看残影并清理入口。
- 切入残影处理直接生成当前文字的只读预览并定位其全图记录。选中文字改变时重新检查；保留框选无文字入口。禁止切页签自动确认或清理。
- 对象来源在面、线、文字中占满页签剩余高度，取消 240px 上限；删除对象保留底部独立位置。
- 导航位置固定，检查内容在导航下滚动。保留数据状态、分页、筛选、批量操作、OCR 候选与来源链、草稿、确认、撤销、线层及文字层保护规则。
- 不改变后端数据模型。测试使用模拟项目及仓库内 runtime 目录，正式项目只读。

实现复用现有检查组件，并保持它们挂载。属性卡不再以选中对象为 React key 重建，避免选择候选时清空工作区。

验证覆盖：切页签自动只读检查、错误重试、改变选中对象、草稿保存顺序、表格显示范围、三层来源高度、检查页签归属、批量核对和移动端/双图对照。
