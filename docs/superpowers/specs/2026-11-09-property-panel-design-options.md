# 面、线、文字属性面板建议

## 本轮用户明确要求

- 文字核对使用页签式筛选：待核对、稍后处理、已确认、全部。
- 删除主表每行详情，原始候选、识别分数、上下标直接进入表格。
- 面、线、文字的删除入口应在对象来源下方。

前两项已独立完成并验证：文字页签、七列表格（含原始候选、识别分数、上下标），移除每行详情。对象面板布局与自动保存仍为本轮建议，用户可选择保存方式；尚未重排三类属性面板或新增面删除命令。

## 推荐统一结构

外观属性、选择与分组、几何操作、对象来源、删除对象。属性常驻，其他分组可折叠；删除按钮位于来源之后，独占底行。未选中时用简短提示代替大面积禁用按钮。

面属性使用填充色；面积筛选、相邻同色、选区扩展/收缩与逻辑分组分开。合并操作使用合并相邻面、按连通组分别合并，碎面操作使用查找可合并碎面。

线属性使用线颜色、线宽、线用途；连接参数使用最大连接间距（px），操作使用连接所选线、移入隔离层、按线宽生成面、沿线切分面。

文字属性保留原图裁剪、文字内容、字号/角度、X/Y/W/H、颜色；独立文字核对、残影处理。确认动作不与自动保存混同。补录文字单独入口。

## 推荐保存策略

单个对象编辑即画布预览，停顿约 600 毫秒或输入框失焦后自动保存。中文输入法组合、无效数字和不完整色值只保留草稿；同一输入过程合并写入，项目命令串行，冲突不静默覆盖。明确显示保存中、已保存、保存失败，失败保留草稿并提供重试。撤销与对象切换需协调待保存内容。

多选保留“应用到 N 个对象”，只提交用户改动字段；属性值不同时显示多个值。图中 17,847 个面不逐键批量写入。文字人工审核保留独立确认，确认前先完成有效编辑保存。

## 当前实现约束

线和单文字删除已有命令与历史恢复；delete_faces 当前尚缺失，新增面删除需补后端索引、关联、事务及撤销。面删除应明确表示留下空缺，不能暗中用相邻面覆盖。
