# 属性区折叠、批量删除与面修复

## 明确实施项

- 面、线、文字外观属性采用同款折叠标题，默认展开，删除重复静态标题。文字核对与残影处理也折叠，默认展开；普通操作统一默认按钮，删除保留危险样式。
- 面线沿用选区批量删除，文字补齐多目标原子删除与撤销。底部对象来源之后“删除 N 个对象”，列表复选仅当前页，切页/筛选清空避免隐藏选择；选中后出现批量操作条。
- 两张文字表合并为feature_id唯一行的表。保留原始候选、分数、上下标等既有列，新增残影检查列；核对review_status是事实，扫描建议content_status不能覆盖。未检查不等于无残影，报告绑定项目/资产/修订，过期清除。

## 面几何事实与修复语义

用户图3高可信对应面 `2d081611-5d76-449d-afe2-e8a98d3f87ea`，青色# a5d2cf，单Polygon，5个孔共39px²均被其他active面占据。全资产coverage有效，无空缺或重叠。冻结B2c旧任务生成该面，尚无证据表明由本轮算法新增。

“去除线状附着”处理面边界的窄枝，不等于删除独立线；只有宽度/长宽比不能区分真实地质薄层，不能全图buffer opening或删除所有小组件。

“填充空洞”仅填孔区域减去其他active面的未占用部分；不能覆盖相邻或内部其他面。内部已占用孔应提供“合并内部碎面”候选，经原图核对和归属选择后单独处理。线/文字对象、原图、原始算法工件保持不变；几何修改必须有效、无新增重叠、审计可撤销。

已建立诊断预览：窄枝候选、孔与占有者、保护线/其他地质对象。受约束应用必须显式选择候选与合法共边接收面；相交保护对象还需逐项确认。未知归属候选不自动删除；被占用孔不直接填充。自动识别阶段默认B2c管线未改变，工具用于核对后的局部面归属修复。
