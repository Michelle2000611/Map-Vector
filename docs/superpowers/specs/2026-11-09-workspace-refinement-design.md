# 编辑工作区整理

用户要求继续实现六项界面调整，随后已明确选择：X/Y/W/H四格，W/H只读；文字以“保存并确认”为主按钮，旁边保留“保存修改”。其余按原截图意图实施，不再设置额外审批点。

- 查看工具区依次为底图选择、图层开关、当前编辑图层不透明度、双图对照。移除“底图”“显示”的可见标签，保留无障碍名称。不透明度使用0–100%的拖动滑块，拖动时实时预览当前图层，松开后单次保存；显示当前百分比，保留键盘操作与无障碍名称。持久化仅修改当前图层，不改其他图层。
- 删除属性区的“图例样式与图层”编辑折叠。保留已有样式读取和渲染，不清空项目样式、草稿或历史。
- 文字位置区以X/Y显示现有文字锚点像素坐标，W/H显示已保存对象旋转后的轴对齐边界框尺寸，只读；不把该尺寸写成新的排版数据。保留X/Y未舍入值和草稿。
- 文字按钮分为保存审核、补录残影。主操作“保存并确认”，次操作“保存修改”；保留单独确认、暂时跳过和下一条待审。分流门槛仅在下方审核栏设置。文字和线删除单独放底部，线操作使用具体动词并标明接线间距单位。
- 删除“面线编辑/文字审核”模式行。统一工作区中选择文字图层才显示左右画布下方的“文字审核与残影”；首次按需挂载，之后隐藏而不卸载，保留筛选、门槛、分页。审核定位不关闭栏，画布不重新挂载。
- 隐藏图层提示移至工具卡下方，显示当前图层名称和恢复显示按钮，仍禁止在隐藏图层编辑。画布内不放此提示。

旧review路径与mode=review链接仍初始化文字层；切回面线后URL和刷新保持一致。项目/资产切换、草稿恢复、异步请求隔离沿用现有规则。

验收覆盖工具布局、只读宽高、不透明度拖动实时预览及松开单次持久化、按钮实际请求、隐藏层阻止编辑、审核栏条件与状态保留、画布DOM/缩放/滚动不变，以及1580/1100/720宽度。滑块另核对0%与100%边界、键盘操作、失败回显及跨图层隔离。验证使用隔离API夹具和实际项目副本，不修改原项目。
